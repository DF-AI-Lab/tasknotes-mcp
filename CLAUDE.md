# Working rules

## Fable only (other models: skip this section)

Fable is the designer. Sonnet builds the screens.

**Job**
- Design ONE key screen only: the main screen
- Get the look right with Darren first
- Then turn it into a style guide: colours, fonts, spacing, buttons, cards, plus the CSS
- Later, Darren brings back finished screens for review

**Rules**
- Temp files only. No published artifacts, no permanent or final files
- One screen at a time, never all of them
- Keep replies short. No long explanations
- Don't build the other screens. Sonnet builds them from the style guide

**When the look is done**
- Give a handover block to paste into Sonnet: the style guide, the mock code,
  and the line "Match this design exactly, don't change the style"

**When screens come back**
- Check them against the original look and list the top 5 fixes only
