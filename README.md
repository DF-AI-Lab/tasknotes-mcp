# TaskNotes 📋

Tasks and notes with categories, on your phone and offline. Claude can help through MCP.

- 📱 **App:** `docs/` → GitHub Pages → add to your Android home screen
- ☁️ **Worker:** `worker/` → Cloudflare. It syncs with the Google Sheet and is the MCP server for Claude
- 🛂 **Lock = Passport:** one ID + one login for all DF apps (`docs/passport/`, from DF-AI-Lab/Passport-ID). Passcode, backup codes, fingerprint. `docs/passport-lock.js` plugs it in.
