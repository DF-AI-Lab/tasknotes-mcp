# Demo 2 changes

Made by Darren. Local-only demo, saved on the device (`tasknotes-demo2`).

## Round 2
- New "Paper" TN icon (also favicon and apple-touch-icon).
- New top bar: icon, month + live clock, ring, three dots.
- The icon is the refresh button. Green dot = up to date, amber dot = update waiting.
- Three dots opens Settings: preview update banner, reset demo.
- Line under the header shows how full the day is (full = 4 hours planned).
- Week strip bars removed to save height.
- Stepped bottom bar with a faint top line.
- Same header height on every screen.
- Late above Pinned, add sheet starts with no category, "Nice work." on Done, extra bottom padding with a fade.
- Tab switch: content nudges sideways, header stays put.
- Bottom bar: line arcs around the raised add button (replaces the step).

## Round 3
- Tick transition "Spring" (picked from 3 mocks: Glide, Fade, Spring).
- Tap the circle: tick pops, a line crosses out the title, then the card lifts and springs to the bottom.
- Done tasks drop to one line with the time they were ticked. Newest done sits at the very bottom.
- Pin button on each task row. Tap it and the card springs to the top. Line icon, no emoji.
- Undo (toast or tapping the tick again) springs it back up.
- No flash or page reset. Turned off if the phone asks for reduced motion.
